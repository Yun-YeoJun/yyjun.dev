# AstroPaper Blog Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 옵시디언으로 작성하고 시리즈로 탐색하며 GitHub Pages에 자동 배포하는 기술 블로그.

**Architecture:** 공식 AstroPaper를 기반으로 콘텐츠 컬렉션과 시리즈 집계 모듈을 추가한다. Markdown 링크 변환은 빌드 플러그인, 시리즈 노출은 공통 집계 함수가 책임진다.

**Tech Stack:** AstroPaper, Astro, TypeScript, Node 24, npm, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-07-blog-design.md`

## Global Constraints

- 본문 `.md`만 허용하며 YAML frontmatter와 표준 Markdown 링크를 사용한다.
- 한국어, Asia/Seoul. 초안/미래 글은 공개하지 않는다.
- 저장소 하위 경로 배포를 지원한다. MIT 라이선스를 보존한다.

### Task 1: 테마와 작성 환경

- [x] 공식 커밋 소스를 가져오고 npm lockfile을 생성한다. `astro.config.ts`, `astro-paper.config.ts`에서 한국어, Markdown, base 설정을 적용한다.
- [x] `src/content/.obsidian/`에 상대 링크, 위키링크 해제, 템플릿 설정을 작성한다. `src/content/_templates/`와 샘플 글/시리즈를 제공한다.
- [x] `src/i18n/lang/ko.ts`, 홈페이지, 소개 페이지의 기본 문구를 한국어로 구성한다.

### Task 2: 시리즈와 Markdown 링크

- [x] `tests/series.test.ts`: 순서가 10, 2, 1인 입력은 1, 2, 10을 반환하고 draft/future 글은 제외하는 테스트를 먼저 작성한다. 중복 회차/미정의 시리즈/누락 필드/음수 회차를 거부하는 사례도 포함한다. `node --test tests/*.test.ts`로 실패를 확인한다.
- [x] `src/utils/series.ts`에 `buildSeries(posts, definitions, now)`를 구현한다. 콘텐츠 스키마에 series/seriesOrder와 series 컬렉션을 추가한다.
- [x] `src/pages/series/index.astro`, `src/pages/series/[id].astro`, `src/components/SeriesNav.astro`를 작성한다. 글 페이지와 헤더에 연결한다.
- [x] `tests/markdown.test.ts`에서 상대 Markdown 링크 변환, 앵커 보존, subpath와 잘못된 대상의 실패를 검증한다. `src/utils/remarkContentLinks.ts`로 구현한다.
- [x] `npm test`로 동작을 확인한다.

### Task 3: 배포와 사용자 안내

- [x] `.github/workflows/deploy.yml`에 main 배포/PR 검증, 최소 권한, npm ci, 테스트와 빌드를 구성한다.
- [x] README에 시작 명령, 옵시디언 보관함, 시리즈 작성법, GitHub Pages 최초 설정, 도메인과 초안 공개 범위를 안내한다.
- [x] `npm run lint`, `npm test`, `npm run build`를 실행한다. 루트 및 `/blog` 빌드의 HTML 내부 링크/이미지, 시리즈 정렬, 초안 제외를 검증한다.
- [x] 결과를 검토하고 구현 완료 범위와 원격 연결에 남은 절차를 보고한다.

## 검증 기록

- 공식 AstroPaper 소스 가져오기와 npm 설치 완료. 빈 읽기 전용 `.git`으로 인해 커밋/푸시는 수행하지 않음.
- 시리즈/Markdown/실제 빌드 링크 테스트 14개 통과, 타입 검사 오류 0개.
- 루트와 `/blog` 배포 경로 모두 15개 HTML 페이지 생성 및 내부 링크·이미지·앵커 검사 통과. 공개 글 3편이 한국어 검색 색인에 포함됨.
- 생성된 HTML에서 시리즈 회차 순서, 현재 회차 표시, 이전/다음 링크, 초안 페이지 및 RSS 제외를 확인함.
- 한글 OG 이미지를 직접 열어 렌더링 확인.
- 별도 리뷰에서 발견한 초안 간 링크 차단과 빈 시리즈 대상 링크를 수정함.
- 임시 미래 글과 고정 시간을 사용해 캐시 재사용 문제를 재현하고 `astro build --force`로 해결됨을 확인함. 검증용 글은 제거함.
- 원격 저장소 주소 미제공. GitHub Actions 실제 실행과 원격 배포는 미검증. README에 최초 연결 절차를 제공함.
