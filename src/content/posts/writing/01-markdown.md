글을 작성할 때는 제목, 문단, 목록, 링크, 코드 블록만으로도 내용을 충분히 전달할 수 있습니다.

## 목차

## 제목과 문단

글 제목은 상단의 `title`에 적고, 본문은 두 번째 수준 제목부터 시작합니다.
문단 사이에는 빈 줄을 넣습니다.

## 코드 남기기

코드 블록에 언어를 지정하면 문법에 맞춰 색상이 표시됩니다.

```typescript
const message: string = "기록은 다음 문제를 해결하는 출발점입니다.";
console.log(message);
```
